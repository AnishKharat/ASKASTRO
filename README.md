# AskAstro

A mobile chatbot for personal astrology insights. Real planetary positions come from Swiss Ephemeris; an LLM turns them into warm, grounded readings.

> For reflection and entertainment only. Not medical, legal, or financial advice.

## Stack
- `app/` — React Native (Expo, TypeScript)
- `backend/` — Python FastAPI (LLM via Claude API or local Ollama)

## Status
Early development. Phase 1: chat app with a streaming backend.
